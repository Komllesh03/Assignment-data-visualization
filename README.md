
# Exploring Malaysia Through Data

## Scientific Visualization Project

This project explores three important aspects of Malaysia using data visualization.

### 1. Household Income
Analyses changes in mean and median household income across Malaysian states from 1970 to 2024.

### 2. Marriage Statistics
Examines marriage trends and differences between males and females across Malaysian states from 2017 to 2024.

### 3. Schools by District
Investigates the distribution of schools across Malaysian states, districts and education stages from 2017 to 2025.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Streamlit

## Project Structure
- `app.py` – Main application homepage
- `pages/` – Individual visualization pages
- `visualization.py` – Reusable visualization functions
- `requirements.txt` – Required Python libraries
- `test.py` – Chart image testing
